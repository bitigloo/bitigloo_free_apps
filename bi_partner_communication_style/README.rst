=====================================
Partner (Contact) Communication Style
=====================================

This is a very simple module which is written to identify the communication style with the partner (formal/informal)

**Features:**
  * possibility to select a communication style on the partner (contact) form
  * you can use this field to identify how to communicate with the partner, e.g. dynamically on the reports or email templates.

**Table of contents**
~~~~~~~~~~~~~~~~~~~~~

.. contents::
   :local:

Configuration:
==============

To configure this module, you need to select the communication style on the contact.

You have two options:
    * *1. Formal*: which is the default
    * *2. Informal*

      .. figure:: ./static/description/partner_communication_style.png
         :width: 100 %
         :align: center

How to Use:
===========

After the checkbox set to True as described above, then:


#. You can use this field to identify how to communicate with the partner, e.g. dynamically on the reports:
