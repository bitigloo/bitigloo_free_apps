Restore Mobile Field on Partner (Contact) with Upgrade Script

This module brings back the mobile number field on the Partner (Contact) form in Odoo 19, which was removed in the standard version.

Features

  • Restores Mobile Field on Partner Form
  • Automatic Data Migration from "Previous Mobile" Messages
  • Integrated with Phone Search Logic
  • Consistent UI with Mobile Icon
  • Configuration
  • How to Use
  • Support
  • Release Notes

No specific configuration is required.
Install the module normally. The post-init hook will automatically run to migrate any existing mobile numbers found in the chatter messages.


Simply open any contact form. You will see the Mobile field below the Phone field.




Also in the Kanban view you will see the Mobile field.



The Mobile field is also added to the Lead/Opportunity form.
