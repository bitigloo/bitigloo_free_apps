=======================================
Auto-Unassign User On Task Stage Change
=======================================

This module was written to unassign user when we change the stage

**Features:**
  * possibility to automate unassigning the users based on a setting on task stage.

**Table of contents**
~~~~~~~~~~~~~~~~~~~~~

.. contents::
   :local:


How to Use:
===========

#. From *Configuration / Task Stages*, choose the stage where you want to unassign user(s), then you can
   select "Unassign" field:

      :width: 100 %
