===============================================
Tag on Invoice, Bill, or any Journal Entry type
===============================================

This module is written to give the user the possibility to add a tag on any journal entry (invoice, bill, credit note, refund bill).

**Features:**
  * creating tags as many as possible,
  * possibility to define color for the tag
  * possibility to prioritize some tags by ranking them in the list view
  * possibility to select many tags on the journal entries

Configuration:
==============

You can add new tags in the list view of tags under:

* Go to *Invoicing (Accounting) / Configuration / Tags / Journal Entry Tags*.
* Easily add a new tag.

   .. figure:: ./static/description/tag_menu.png
      :width: 100 %
      :align: center

* On the list view, with the help of the handle |icon|, you can order the tags:

.. |icon| image:: ./static/description/handle.png
   :height: 1em

How to Use:
===========

Simply open any journal entry (i.e. any invoice, bill, credit note, refund bill or other types of journL entries):

#. Under the tab "Other Info", after the field "To Check", you can add a tag:

   .. figure:: ./static/description/bill.png
      :width: 100 %
      :align: center

   .. figure:: ./static/description/invoice.png
      :width: 100 %
      :align: center


**Notes:**
   * The create and edit of the tags is restricted to the Bookkeeper access group.
