================================
Automated Activity on Task Stage
================================

This module was written to add activity automated on a Task Stage

**Features:**
  * adding activity automated when to move on a stage

**Table of contents**
~~~~~~~~~~~~~~~~~~~~~

.. contents::
   :local:


How to Use:
===========

#. From *Configuration / Task Stages*, choose the stage where you want to create
   automated activity, then you can select "Activity Type".
   You will then need to select the "User Type": 'Project Manager' or 'Specific User'.
   If the Specific User is selected, you will then need to define the user.
